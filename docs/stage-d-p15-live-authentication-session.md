## Goal

Turn the Stage D structural-read closure from postures into a **live, receiver-owned gate**: over a real shell gesture, the receiver performs the local authentication event (the D-P6 record) and the knowledge-factor challenge-response (the D-P8 mechanic), re-inspects its own frozen private-read activation through the frozen D-P10 gate over the raw leg records, and binds the whole into one live, session-scoped, restart-expiring, receiver-retractable establishment — then a thin read gate admits the **live use** of the already-closed single-principal structural-read postures for that session. Nothing else: no chat lane, no agent session, no memory lane, no current truth, no write/send/sign.

Owner-confirmed scope (2026-09-29): the desktop shell is the **shared presentation frame for the receiver's agent family** (`sharedSurfacePosture: desktop_shell_shared_presentation_frame_session_stays_receiver_owned_no_scope_collapse`) while the session itself stays strictly receiver-owned — Agent0 and every other observed agent gain no session, no secret, no admission (`agentScopePosture: no_agent_session_no_agent_secret_no_agent_admission`), and no scope ever collapses.

## Load-bearing mechanism

- **The freshness asymmetry the legs carry.** The D-P9 composition's freshness diagnosis covers only the D-P8 leg; the D-P5 and D-P9 legs are structural-only (no clock). So the live lane hands the frozen D-P10 gate a **fresh receiver-explicit D-P10 activation record built at establishment time** (`receiver_explicit_activation_not_inferred`, `activated_at_epoch_ms = now`) — the record kind exists for exactly this receiver act, zero frozen changes — and the establishment then demands the frozen D-P10 gate's own positive state (`fixture_structural_session_scoped_private_read_activation`) mapped verbatim in the echo.
- **Restart expiry is a receiver-recorded postural fact, not a timer.** `establishmentScopePosture: live_session_scoped_receiver_shell_restart_ends_establishment` is a record the establishment check demands; the refused alternative (`shell_process_scope_not_restart_ending_refused`) is arm 11 — a session that silently survives restart refuses at its own cause. The clock-side twin is arm 12: expiry is proven by pure parameter arithmetic (evaluate at `established_at + maximumAge + 1` → refuse `session_establishment_not_session_current`) — no sleeping, no clock injection, the contract stays pure.
- **Retraction is checked first-class and before the legs.** A present retraction fact refuses outright regardless of how fresh the legs once were (arm 10), with the freshness diagnosis still honest — the D-P14 invalid-arm-first, echo-readable discipline.
- **The frozen D-P6/D-P8 mismatch law is inherited verbatim.** An honest digest mismatch is a well-formed record whose verification still fails closed (`not_verified` / `receiver_challenge_proof_incomplete` — never a "mismatch" state), a claimed comparison that contradicts the receiver's own recomputation is refused at the recompute-agreement cause, and a salt flip (proof salt ≠ verifier salt) refuses at the knowledge-factor cause with the same incomplete literal echoed.
- **Cause order.** Record validity first (with the raw evaluation pair diagnosed even there), then retraction, then session currency, then the D-P6 observation, then the D-P8 knowledge factor, then the frozen D-P10 activation re-run, then the declarative scope/agent/frame check, then the full proof check — each cause reads its own mapped echo; nothing downstream of a cause is claimed (the D-P13 ladder mold, no defensive literal).
- **Echoes stay readable through broken legs.** The D-P6, D-P8 (comparison + recomputed comparison + freshness), and D-P10 echoes are computed on every arm — a missing secret diagnoses `unknown` honestly, a stale event echoes its staleness while the frozen D-P10 echo stays active underneath (the frozen gate predates D-P6 — the honest mismatch D-P14 pinned), an expired re-assessment carries stale ages on its own echo and the leg echoes.
- **The forbidden-key inventory widened once.** The gate's deep-walk inventory is the frozen D-P14 base (the widest frozen inventory to date) plus four keys this cut exists to refuse: `agentSession`, `agentSecret`, `agentAdmission`, `chatMessage`. Exact-key deep walk; the cut's own longer key names containing the fragment `session` are unaffected mechanically.
