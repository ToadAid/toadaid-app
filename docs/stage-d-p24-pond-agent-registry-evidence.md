The desk's url-shaped values (the type URI, the image pointer, the service endpoints) never enter this repository — the digest is the pin; the values live in the source.
- **Two-state, six-cause ladder.** State set: `agent_registration_evidence_not_presentation_ready | agent_registration_evidence_presented_derived_evidence_only_no_admission_no_channel`. Causes in ladder order: `agent_registration_evidence_record_invalid` → `registration_digest_agreement_not_proven` → `onchain_coordinate_claimed_without_onchain_evidence` → `agent_registration_evidence_not_fresh` → `receiver_registration_evidence_proof_incomplete` → `agent_registration_evidence_derived_evidence_only_presentation_satisfied`. The type-kind vocabulary (2 values) makes an unrecognized-but-well-formed self-describing document presentable — generality without authority (the template is fillable by OpenClaw, Hermes, anything self-describing).
