## Goal

The receiver **records a reply REQUEST over a currently admitted D-P16 conversation record**, assessed by one frozen ceremony (`assessPondReplyRequestDecision`) whose core mechanism is the established house re-run — the frozen D-P16 `assessPondConversationRecordAdmission` over a dedicated 14-key leg projection at the SAME evaluation pair; the request records only when the re-run verdict is `conversation_record_admitted`. The recorded state is `reply_request_recorded_session_scoped_no_reply_composed` — **composition is refused in the state set itself; no composed state exists** (the runway literal names the future cause swap, deviation 6). Over a currently recorded request, the receiver records ONE **provider decision** — the local-runtime `ollama` selection, the exactly-one performable member of the declared cognition-provider vocabulary (type-only substrate, re-declared verbatim with Equal ties; no backend profile, no modelRef/harnessRef) — assessed by `assessPondCognitionProviderDecision`, which re-runs the frozen reply-request ceremony over its 15-key legs (four echo depths to D-P15) and performs NO inference, authentication, routing, fallback, or provider contact. In parallel, a **standing claimed-reply wall** (`assessPondClaimedAgentReplyRefusal`) refuses every claimed agent reply on every path with ZERO echo of the claimed text or responder — there is no open branch, no composer, and nothing stored. A future runtime cut swaps the refusal causes for composed replies; this cut composes nothing.

## Load-bearing mechanism

- **The request re-runs the conversation record it requests a reply over.** The decision re-runs the frozen D-P16 `assessPondConversationRecordAdmission` over a dedicated 14-key projection (`fullConversationLegs`), never the 15-key input spread, so the request record itself is never handed to the D-P16 re-run; the requested copy is the D-P16 record verbatim (dv/kind preserved, never re-stamped).

A refusal any depth down (retraction → gate refusal → conversation reassessment → request echo → provider echo) stays readable at its own depth.
