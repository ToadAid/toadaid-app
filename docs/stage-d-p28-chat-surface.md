## Load-bearing mechanism

- **Correlation through the frozen lanes' own exports, never through new state.** The transcript module (`ui/pond-chat-surface.js`) reads only the seven posture exports — `currentConversationSurfacePosture`, `currentDeliveryPosture`, `currentDispatchPosture`, `currentReceiptPosture`, `currentTransportPosture`, `currentReplyPosture`, `currentVoicePosture` — at one shared evaluation instant, and walks the lanes' own index chain: conversation record → delivery decisions (`conversationRecordIndex`) → dispatch decisions (`deliveryDecisionIndex`) → receipts (`dispatchDecisionIndex`); policies hang off the delivery decision; reply requests off the conversation record; voice (session-scoped, no record index) renders as the transcript's footer posture line only when held. A refused composition stores nothing in the lanes, so it appears nowhere in the transcript.
- **Single-state verdicts, honest confinedness.** The receipts lane records only its performable `delivered` state, the transport lane only its in-process policy, and the reply lane only its request state (a refused input stores nothing), so those rows' verdicts are the lane's one recorded value; delivery and dispatch rows speak from their lanes' re-assessed state values through fixed label maps with raw-value fallback. Post-session confinedness rides the lanes' own `presentationMark` values (`inspection-only`, `confined · reassessment refuses`), mapped with the same fallback discipline; unmapped values render verbatim.
- **Re-presentation without mutation.** The transcript re-renders on document clicks (every lane mutation is click-driven, so a post-handler click re-run sees the fresh posture re-reads, and the listener sits one bubble level above where handlers run), on window focus, and on shell navigation (`popstate`) — covering the case where the live session is established or retracted from the Agents view between transcript views. No timer, no MutationObserver, no state, no cache: every render is a fresh read of the frozen lenses.
- **Fail-closed renderer discipline.** Missing document or target → `false` before anything renders; textContent only (`innerHTML` never appears); no transport or storage primitive; no record of its own (no module-scope record/decision array exists); no lane record call reaches it (each of the eight `record*` / `perform*` functions is asserted absent from the module text).
- **The freeze and the collapse.** Zero lane module edits: the seven lane stacks plus the D-P16 contract surface keep their exact frozen note/status/list/wall targets, now inside `<details class="lane-stack">` elements — default-closed, opening to the full established panels; `pond-conversation.js`, `pond-…delivery/dispatch/receipts/transport/replies/voice.js` are byte-untouched, and none of them mentions the new lane (asserted). The cockpit-note lifecycle line stays verbatim at the form's foot; the mic button stays `disabled` with its exact `aria-label`.
